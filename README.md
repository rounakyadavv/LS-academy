# LS Academy Website

Premium responsive static website for LS Academy, ready for GitHub Pages or Vercel.

## Edit Institute Details

Update `config.js` to change address, phone, Instagram, subjects, fees, faculty, timings, gallery, testimonials, statistics, admissions, and FAQs.

## Replace Logo

Replace `assets/logo.png` with your final LS Academy logo using the same filename, or update `institute.logo` in `config.js`.

## Deploy

Upload the full `ls-academy-site` folder to GitHub Pages, Vercel, Netlify, or any static hosting provider. The entry file is `index.html`.

## Notes

- Contact form opens WhatsApp with a pre-filled enquiry.
- Google Maps uses an editable embed URL in `config.js`.
- Gallery uses editable visual placeholders until real classroom photos are available.
